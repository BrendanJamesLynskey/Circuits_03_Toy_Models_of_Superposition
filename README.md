# Circuits 03 — Toy Models of Superposition

**Toy Models of Superposition** (Elhage, Hume, Olsson et al., Anthropic, September 2022) is the paper that explains why neural-network neurons are so hard to interpret. It starts from the **linear representation hypothesis** — that **features are directions** in activation space — and the distinction between **monosemantic** neurons (one feature each) and **polysemantic** ones (many features each). Its central idea is **superposition**: a network can represent *more features than it has dimensions* by assigning them **near-orthogonal directions** and tolerating a little **interference**, an over-complete, compressed-sensing-style code that pays off because real features are **sparse**. Using a tiny linear-plus-**ReLU** autoencoder — projecting `n` sparse features through an `m < n` bottleneck and reconstructing them — the authors show that **importance** and **sparsity** drive sharp **phase transitions** between a monosemantic regime and superposition, and that superposed features crystallise into clean **geometric structures** (antipodal pairs, triangles, pentagons, tetrahedra, **tegum products**) with **fractional dimensions per feature**. Superposition is the mechanistic reason neurons are polysemantic, and it links interpretability to **adversarial examples** and **double descent**. For a practising engineer, the lesson is blunt: **you cannot read a model neuron-by-neuron** — which is exactly why **dictionary learning / sparse autoencoders** (the next deck) are needed to recover the true features.
